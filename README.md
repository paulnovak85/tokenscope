# TokenScope — 大模型 Token 成本计算与对比工具

## 作品简介

TokenScope 是一个纯静态网页小工具，帮开发者和产品团队在选大模型之前，先把 Token 这笔账算清楚：输入一次请求的输入/输出 token 数和每日请求量，即可得到单次、日、月成本（美元并按可编辑汇率折算人民币），并横向对比 11 个主流模型的月成本，给出最省方案和最贵方案的差距。

- 形式：纯静态网页应用，零依赖、零构建
- 语言：中文 UI
- 许可：MIT（见 `LICENSE`）

## 解决的问题

1. **选型只看单价，不看总账。** 单价表上的数字很抽象，乘上真实业务量之后，月成本可能差出几十倍，团队往往上线后才发现账单超标。
2. **不知道自己的提示词有多“贵”。** 一段长提示词到底是多少 tokens、在每个模型上跑一次多少钱，缺少顺手可用的估算工具。
3. **比价靠手工拉表格。** 各厂商报价页格式不一，手工 Excel 对比慢且容易过期；价格一变就要全部重算。

## 功能列表

- **成本计算器**：滑杆 + 数字框调输入 tokens、输出 tokens，填每日请求数，选模型后实时算出单次 / 日 / 月成本（美元 + 按可编辑汇率换算的人民币）。
- **模型对比表**：内置 11 个主流模型参考单价（输入/输出，每 1M tokens 美元价），覆盖 OpenAI GPT-5 系列、Anthropic Claude、Google Gemini、DeepSeek、阿里通义千问 Qwen、MiniMax。价格明确标注为“参考价，可编辑”，表格内可直接修改，改后所有计算实时更新，并可一键恢复参考价。
- **对比可视化**：各模型月成本横向条形图（纯 CSS/JS 绘制），最便宜的模型绿色高亮，并给出“最省 vs 最贵每月差多少、一年差多少”。
- **Token 估算器**：粘贴任意文本，按中文以字数、英文以单词/字符的通用近似算法估算 token 数（界面注明为近似估算），同时列出这段文本在各模型上跑一次的输入成本。
- **场景预设**：客服对话、代码助手、长文档摘要、通用聊天机器人四个典型场景，一键填入典型参数。
- **响应式布局**：移动端可正常浏览操作。

## 运行方式

无需安装任何依赖，任选其一：

1. **直接打开**：双击 `index.html` 用浏览器打开即可。
2. **本地静态服务器**（推荐，与开发环境一致）：

   ```bash
   cd tokenscope
   python3 -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```

所有计算都在浏览器本地完成，不发送任何数据。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建步骤、无外部请求。
- 数据与逻辑分离：模型单价集中在 `app.js` 顶部的 `DEFAULT_MODELS` 数组中，增删模型只改这一处。
- 成本公式：`单次成本 = 输入tokens/1e6 × 输入单价 + 输出tokens/1e6 × 输出单价`；月成本按 30 天计算。
- Token 估算为启发式近似（中文约 0.9 token/字、英文按词长折算等），不能替代各厂商官方 tokenizer，仅用于选型阶段的量级估算。
- 价格数据为根据公开资料整理的参考价，不声称实时、不代表厂商官方最新报价，正式选型请以官网为准。

## 后续规划

- 接入各厂商官方 tokenizer（如 tiktoken.js）提供精确计数模式。
- 支持自定义模型：用户可新增自己的模型和私有部署成本（按 GPU 时租折算）。
- 增加用量曲线导入：粘贴一周的请求日志，自动统计真实 token 分布再算成本。
- 增加预算告警线：在条形图上叠加月预算线，一眼看出哪些模型超预算。
