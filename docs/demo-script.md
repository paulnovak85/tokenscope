# TokenScope 演示视频口播脚本（3 分钟）

录制提示：浏览器全屏打开 `index.html`，提前把汇率留在 7.20。全程录屏操作 + 同步口播，不用露脸。

---

## 0:00–0:20 开场

口播：
“选大模型的时候，你有没有算过这笔账：同样一个应用，换一个模型，一个月能差多少钱？今天演示的 TokenScope，就是一个专门算这笔账的小工具——纯静态网页，零依赖，打开就能用。”

画面：停留在页面顶部，鼠标划过标题和四个区域。

## 0:20–0:55 场景预设 + 计算器

口播：
“先点‘客服对话’预设：单次输入 1200 tokens、输出 300、每天 5000 次请求。右边立刻给出单次、日、月成本，还是美元加人民币双币种。再切换到‘长文档摘要’——输入一下涨到 5 万 tokens，注意月成本的变化，长上下文场景的成本，就是这样被低估的。”

画面：依次点击“客服对话”“长文档摘要”两个预设按钮，停顿让观众看清右侧月成本数字。

## 0:55–1:40 模型对比与条形图

口播：
“往下是模型对比。11 个主流模型，从 GPT-5、Claude、Gemini，到 DeepSeek、通义千问、MiniMax，都在同一组参数下算月成本。条形图按从便宜到贵排序，最省的绿色高亮，下面还有一句话总结：最省方案和最贵方案，每月差多少、一年差多少——这个数字通常很扎眼。”

画面：缓慢滚动条形图从最短到最长，停在“最省方案”那行总结文字上。

## 1:40–2:15 价格可编辑

口播：
“我要特别说明：这里的价格都是参考价，而且可以直接改。比如你谈到了折扣价，把输出单价改掉——表格、计算器、条形图全部实时更新。因为真实价格因人而异，工具不该拿一个过期价格冒充标准答案。”

画面：在表格里把当前选中模型的输出价改小，展示月成本和条形图同步变化，然后点“恢复参考价”。

## 2:15–2:45 Token 估算器

口播：
“最后是 token 估算器。把一段真实提示词粘贴进来，它按中文算字数、英文算单词的方式估算 token 数——注意，它会明确告诉你这是近似估算。下面还直接列出：这段文本在每个模型上跑一次，要花多少钱。”

画面：点击“填入示例文本”，展示字符数、估算 tokens 和各模型单次成本表。

## 2:45–3:00 收尾

口播：
“TokenScope 的想法很小：选模型之前，先算清账。代码是 MIT 开源的，双击就能跑，欢迎大家试用。谢谢。”

画面：回到页面顶部，全屏停留 2 秒结束。
