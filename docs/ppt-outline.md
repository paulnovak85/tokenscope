# TokenScope 赛事介绍 PPT 大纲

逐页文案：每页包含标题、页面要点、口播备注。建议 8 页，控制在 5 分钟讲解内。

---

## 第 1 页 · 封面

**标题**：TokenScope — 大模型 Token 成本计算与对比工具
**副标题**：选模型之前，先算清账

页面要点：
- 作品名称 + 一句话定位
- 纯静态网页 · 零依赖 · 即开即用

口播备注：
“大家好，我的作品叫 TokenScope。它解决一个很具体的问题：用大模型之前，先把成本算清楚。”

---

## 第 2 页 · 痛点

**标题**：痛点：账单出来，才发现选错了模型

页面要点：
- 单价表很抽象：$3/1M tokens 到底贵不贵，不乘业务量根本没感觉
- 同一应用换个模型，月成本能差几十倍，上线后才爆雷
- 提示词越写越长，没人知道一段 prompt 到底值多少钱
- 比价靠手工拉 Excel，价格一更新全部作废

口播备注：
“很多团队选模型只看跑分和单价。单价差 3 倍不吓人，但乘上每天几万次请求，一个月就是几千上万的差距。”

---

## 第 3 页 · 方案

**标题**：方案：三步算清 Token 账

页面要点：
- 第一步 估用量：粘贴文本，估算 token 数
- 第二步 比价格：11 个主流模型同参数横向对比
- 第三步 选方案：条形图直观看差距，最省方案高亮

口播备注：
“TokenScope 的流程就三步：先估自己用多少 token，再把同样的用量放到 11 个模型上算月成本，最后用一张图选出方案。”

---

## 第 4 页 · 功能演示（一）成本计算器

**标题**：功能演示：成本计算器 + 场景预设

页面要点：
- 滑杆调节输入/输出 tokens、每日请求数
- 单次 / 日 / 月成本实时呈现，美元 + 人民币双币种
- 客服、代码助手、长文档摘要等场景一键填充

口播备注：
“演示时我点一下‘长文档摘要’预设：单次输入 5 万 tokens。注意看月成本——这就是长上下文场景最容易低估的地方。”

---

## 第 5 页 · 功能演示（二）模型对比

**标题**：功能演示：可编辑的价格表 + 对比条形图

页面要点：
- 11 个模型参考单价表，价格可直接改、全量实时重算
- 月成本条形图从低到高排序，最省方案绿色高亮
- 自动算出最省 vs 最贵：每月差多少、一年差多少

口播备注：
“这里我要强调：表里的价格是参考价，而且故意做成可编辑的。因为真实议价、区域价、缓存折扣都不一样，工具不该假装价格是死的。”

---

## 第 6 页 · 技术架构

**标题**：技术架构：简单到没有架构

页面要点：
- 纯 HTML + CSS + 原生 JS，零依赖、零构建、零后端
- 数据与逻辑分离：模型价格集中在一个数组里维护
- 全部计算在浏览器本地完成，文本不上传，隐私友好
- 双击 index.html 即可运行，也可放任意静态托管

口播备注：
“这个工具的技术选型是刻意的克制：成本计算不需要后端。零依赖保证它五年后打开还能跑，也方便任何人 fork 去改。”

---

## 第 7 页 · 亮点

**标题**：亮点：把“参考价”当产品设计

页面要点：
- 不假装实时官方价：明确标注参考价、鼓励用户改成自己的真实价格
- 双币种呈现：美元报价、人民币预算，汇率可调
- 近似估算讲明算法边界：中文按字、英文按词，误差说在明处
- 一个作品两个场景：既是选型工具，也是 Token 经济科普载体

口播备注：
“市面上的比价工具最大的问题是把过期价格装作权威数据。TokenScope 反过来：价格是假设，用量才是你的事实，工具帮你把两者乘出来。”

---

## 第 8 页 · 规划

**标题**：后续规划

页面要点：
- 接入官方 tokenizer，估算升级为精确计数
- 支持自定义模型与私有部署（GPU 时租）成本折算
- 导入真实请求日志，按 token 分布算成本
- 条形图叠加预算线，超预算模型一眼可见

口播备注：
“接下来会先做日志导入，因为真实业务的 token 分布比任何预设都准。谢谢大家，欢迎试用和提 issue。”
